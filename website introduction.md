# 🌐 Beginner Guide: What Is a Website & What You Need to Create One

## 📌 1. What Is a Website?

A website is a collection of connected web pages that people can access through the internet using a browser (like Chrome, Firefox, or Safari).

A website can include:

- Text
- Images
- Videos
- Buttons and forms
- Products and shopping
- Blog posts
- Contact details

**Examples of websites:**  
google.com • facebook.com • amazon.com • rra.rw • yourbusiness.com

---

## 📌 2. Why Do People Create Websites?

- To show business information
- To sell products
- To share knowledge
- To build a personal brand
- To collect leads or clients
- To offer online services

---

# 🧩 What You Need to Create a Website (Beginner Friendly)

Below are the 5 important things you must have:

---

## ✅ 1. Domain Name

A **domain** is the address people type to visit your website.

**Examples:**

- example.com
- yourbusiness.rw
- myshop.net

**Where to buy domains:**

- SawaSawa
- Hostinger
- Namecheap
- GoDaddy

**Cost:** yearly.

---

## ✅ 2. Hosting

**Hosting** is a server (online computer) where your website files are stored.

**Common hosting companies:**

- SawaSawa
- Hostinger
- Bluehost
- DigitalOcean
- AWS
- Netlify (for static sites)

Hosting keeps your website online **24/7**.

---

## ✅ 3. Website Files (The Website Itself)

This includes everything your site is made of.

### **Frontend – What people see**

- **HTML** → structure  
- **CSS** → design (colors, layout)  
- **JavaScript** → interactions  

### **Backend (Optional, only if needed)**

Used for:

- Login systems
- Databases
- Payment systems
- Admin dashboards

**Backend languages and frameworks:**

- Ruby on Rails
- Python Django
- Node.js
- Laravel (PHP)

If your website is simple (Home, About, Contact), you **don’t need a backend**.

---

## ✅ 4. Website Content

Prepare the information your website will show:

- Business name
- Logo
- Images
- Description
- Mission & vision
- Services
- Products
- Contact info
- Location
- Social media links

**Good content = Professional website.**

---

## ✅ 5. Website Builder or Developer

They create the entire website for you.

### **Option C: Learn Coding (If you want to build it yourself)**

Start with:

- HTML
- CSS
- JavaScript
- Optional: Bootstrap (easier design)

This helps you build custom websites.

---

# 🎯 Example: What You Need for a Small Business Website

- Domain: `mycoffee.rw`
- Hosting plan
- Home • About • Contact pages
- Photos of the business
- About the team
- Services or products
- Social media links
